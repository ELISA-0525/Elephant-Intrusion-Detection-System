
# Multi-Sensor Logic Gate Elephant Intrusion Detection System

### Digital Logic and Computer Organization (DLCO) | NIBM

A group academic hardware project exploring a sensor-based intrusion warning system using digital logic gates and an audible buzzer alarm.

## Project Overview

This project was developed to demonstrate how multiple sensor inputs can be processed using basic digital logic circuits. The prototype was inspired by the problem of human–elephant conflict in Sri Lanka.

Our group designed, assembled and successfully demonstrated a physical hardware prototype. The system activates a buzzer when the configured sensor input conditions are satisfied.

## Project Objectives

- Build a functional sensor-based warning circuit.
- Apply AND and OR digital logic gates to sensor signals.
- Activate an audible alarm based on the configured input conditions.
- Gain practical experience with circuit assembly, testing and troubleshooting.

## Hardware Components

- PIR motion sensor
- Pressure sensor
- Light-dependent resistor (LDR)
- AND and OR logic gate circuitry
- Dot board and supporting circuit connections
- Battery / power supply
- Buzzer

## Working Principle

1. The PIR, pressure and LDR sensors provide input signals.
2. The digital logic circuit processes the input states using AND and OR gates.
3. When the configured alarm condition is satisfied, the circuit activates the buzzer.
4. The buzzer provides a local audible warning.

The system was built as a hardware circuit without a microcontroller, camera, IoT connectivity or SMS notifications.

## Testing and Results

The physical prototype was assembled and successfully demonstrated during the module assessment. The buzzer responded to the intended input conditions, and the group received positive feedback from the lecturer.

The prototype was not field-validated for identifying elephants specifically, and no measured detection range or accuracy is claimed.

## Limitations and Future Improvements

The current prototype is a general sensor-based intrusion warning demonstration. Further development could explore animal classification, outdoor testing, weather protection and remote notifications.

These improvements were not part of the implemented prototype.
